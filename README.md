# GitHub Profile Search 🔍

A ReactJS application that allows users to search for GitHub profiles using the **GitHub API**. This project provides detailed information about GitHub users, including repositories, followers, and more, in a clean and interactive interface.

![Github Profile Search](https://github.com/user-attachments/assets/756687fb-1e00-49c9-9985-4b045133880a)


## Tech Stack 🛠️

- **ReactJS**: For building the user interface.
- **GitHub API**: For fetching user data.
- **Tailwind**: For styling and responsive design.
- **Axios**: For making API requests.

## Features ✨

- **Search Profiles**: Enter a username to fetch profile details.
- **Profile Details**: Displays user information, repositories, followers, and following.
- **Error Handling**: Provides feedback for invalid usernames or API errors.
- **Responsive Design**: Works seamlessly across devices.
